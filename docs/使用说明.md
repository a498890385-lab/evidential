# 依证推事

一个 Windows 小工具：把"我觉得大概率是这样"变成一条**可追溯的贝叶斯证据链**。

- 输入一个待验证的问题，设定先验（最好来自参照类基准率）
- 一条条加证据（手动 / AI 联网搜 / 贴链接 / 贴正文）
- 每加一条，后验概率按贝叶斯定理更新，图表随时可看
- 攒够了就"记录判断"，导出 Markdown / PDF 报告

计算全部本地完成；AI 只负责搜集和整理候选证据，**永远不自动入链**——每条都要你点头。

**安装版**：已安装在 `%LOCALAPPDATA%\Programs\evidential\`，桌面和开始菜单都有快捷方式，卸载走「设置 → 应用」。
**便携版**：`F:\依证推事\依证推事-1.0.0.exe`，单文件免安装，适合放 U 盘。两者共用同一份数据。

---

## 一、快速开始

1. 从桌面快捷方式打开（或双击便携版 `依证推事-1.0.0.exe`）；首次会在 `%APPDATA%\依证推事\` 建数据目录。
2. 点 **「用示例数据看看」**，先用一个 7 条证据的样例熟悉界面。
3. 正式使用时：**新建** → 填问题和两个假设 → 设先验（可稍后改成参照类基准率）。
4. **加证据**：写一句能判真假的命题，选一个似然比档位（五档），保存。
5. 想看 AI 帮忙：**设置** 里填 DeepSeek API Key → 右侧 **「帮我找证据」**。
6. 觉得够了：**导出报告** → 检查预览 → 导出 Markdown 或 PDF。

## 二、几个关键概念（用人话）

| 名词 | 一句话 |
|---|---|
| 先验 | 还没看证据时，你觉得它有多可能。**建议填同类情况的统计比例**，别凭感觉拖滑块 |
| 似然比 | 这条证据在"假设为真"的世界里出现，比在"假设为假"的世界里出现，常见多少倍 |
| 后验 | 看完证据后的新判断，由公式算出来，不是拍脑袋 |
| 决策阈值 | 行动成本 /（行动成本 + 不行动损失）。概率超过它，才值得动手 |

界面上"证据充足度"的四个灯，是判断**能不能下结论**的检查项：
稳健（先验小变动不翻转）、无单点依赖（删掉任何一条不翻盘）、双向覆盖（反证方向搜过）、相关性已处理（同源证据已分组打折）。

## 三、AI 配置

- 默认走 **DeepSeek**（OpenAI 兼容接口）：在 [platform.deepseek.com](https://platform.deepseek.com/) 申请 Key，粘进「设置」。
- 联网搜索默认用 **DeepSeek 自带搜索**（同一把 Key，返回网页正文与权威度）；也可在设置里切到 **博查 Bocha**（需另填 Key）。
- Key 用 Windows 系统加密（Electron safeStorage）保存在本机，**不会写进导出的会话文件**。
- 没有 Key 时，手动加证据、概率更新、报告导出全部照常可用。

## 四、数据存在哪

```
%APPDATA%\依证推事\data\
├─ sessions\       每次会话一个 JSON
├─ backups\        每日备份（保留 14 天）
├─ exports\        报告导出默认目录
└─ settings.json   API Key（加密）
```

会话可以「导出会话文件」成 `.json` 带走，或在另一台机器导入。

## 五、已知限制（写明白，免得误用）

1. **似然值是主观估计**：输出的是"你的信念量化"，不是客观概率，也不是预测。
2. **独立性只是近似**：同源证据靠"分组 + 折扣"缓解，不能完全消除重复计数。
3. **顺序效应**：存在折扣时，单条证据的"影响幅度"与加入顺序有关；最终后验不受影响（无截断时）。
4. **AI 会出错**：候选证据带"引文溯源校验"，校验不过会标黄，必须自己点开原文核对。

## 六、开发者

技术栈：Electron + React + TypeScript + Vite + ECharts。

```bash
npm install                # 依赖（Electron 二进制需要镜像：ELECTRON_MIRROR）
npm run dev                # 开发模式（vite + electron）
npm test                   # 领域层单测（贝叶斯内核 18 条）
npm run build:web          # 构建前端
npm run dist               # 打包 portable exe（输出到 release/）
```

目录：

```
electron/        主进程：窗口、IPC、存储、密钥、AI、PDF
src/domain/      纯 TS 贝叶斯内核（可单测，不依赖 React）
src/ui/          界面组件
src/store.ts     状态与自动保存
tests/           领域层测试
tools/           开发期自动化脚本（CDP 截图/冒烟、图标生成）
docs/            设计规格（在仓库外层 docs/）
```

核心公式：`logit(P) += logBF`，多假设时 `P(Hi|E) ∝ P(Hi)·LRi` 后归一化；所有派生概率都由 `replay(session)` 重算，不存"权威值"。
